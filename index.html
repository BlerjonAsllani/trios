01 / Trits statt Bits

Ein Trit hat drei Zustände: −1, 0, +1. Von rechts nach links stehen die Stellen für 1, 3, 9, 27, 81 und 243. 000+0− bedeutet deshalb 9 − 1 = 8.

02 / Dein erster Code

LI a, 8     ; Zahl ins Register a
ADD a, #5   ; fünf addieren
SYS 1       ; Ergebnis ausgeben
SYS 0       ; Programm beenden

Im Einzelschritt siehst du auch den Wechsel in den Kernel.

03 / Eine virtuelle Maschine

Dein Mac führt die Simulation aus. Bootcode und Systemaufrufhandler laufen als Programme auf der ternären CPU; Speicher, Geräte und Prozesswechsel werden vom Emulator verwaltet.

Dies ist ein experimentelles Lernbetriebssystem innerhalb von macOS.
